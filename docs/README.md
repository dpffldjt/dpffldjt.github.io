# dpffldjt.github.io
## Project Purpose
This project is intended for intermediate Korean learners. At this stage, many learners are encouraged to discover new language through native content, but many learners are also intimidated by the scale of movies, shows, and novels. Learning new vocabulary (and sometimes grammar!) can bridge the gap between learner-driven content and native content without feeling like a continuation of the sometimes-boring textbook study stage.
