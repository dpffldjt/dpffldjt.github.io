# Retrospective
## What went well
Processing vocabulary/grammar went well, including styling as well as checking meanings/usage and formatting that information in the site. Also, since I was already familiar with HTML and CSS, that was not too much of a hurdle, though some things did require searching to refresh my memory.
## What went wrong
Styling CSS navigation, both within the page and across pages, continues to be difficult for me, and eventually I had to rework the entire navigation to simply it. 
Also, in terms of the project as a whole, I did not give myself enough time to complete it without feeling like I was rushing. Starting the work I could have started in advance, like processing the lyrics or choosing a colour scheme, would have given me more time to work on the more difficult tasks before the deadline.
## What you'd do differently
Next time, I'll start work on the things I know I can do early in advance. Also, I'd give myself more time to research how to properly style nav bars and page navigation to fully implement the vision I have for the site.
