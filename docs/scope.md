# Elliot Pope -- Final Project Scope Statement
## Project Purpose
The purpose of this project is to create a website for learners of Korean to study
vocabulary and grammar through song lyrics.
## Description
This project will include a home page for navigation and subpages for each song.
Words and grammar structures will be colour-coded, one colour for grammar as a
whole and one for each part of speech. This will be focused on intermediate and
advanced level vocabulary and grammar and will not break down beginner points.
## Desired Results
This project will have one homepage with an easy-to-expand navigation format for
future additions. It will have one subpage with just one example song due to time
constraints. That subpage will include the colour-coded lyrics as well as a list
underneath the images with vocabulary with meanings in English and grammar with
brief explanations and one or two example sentences.
## Exclusions
This project will not include future songs or other planned features like
vocabulary practice exercises or grammar explanations outside of brief explanations
along with the song.
## Feedback loops
The scope will be updated based on peer feedback. Otherwise, there is no feedback given throughout this project.
